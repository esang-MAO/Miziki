# Miziki

A local-first music player for iPhone, installed from Safari to the home screen, served from GitHub Pages at [esang-mao.github.io/Miziki/miziki.html](https://esang-mao.github.io/Miziki/miziki.html). It plays FLAC, WAV, ALAC and MP3 files you pick from your own device. Nothing is uploaded — an optional social layer sits on top, and the player works fully without it.

See [CLAUDE.md](CLAUDE.md) for the repo layout, how the app is put together, and the development commands.
