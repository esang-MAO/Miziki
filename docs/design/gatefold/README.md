# Gatefold designs (docs/29_GATEFOLD.md)

Canvas "Miziki Gatefold", Nov 4 2026. Phone frames are 390×844; the desktop frame is 1280×800. Drawn against the repo's real tokens (`00-base.css`), the four self-hosted fonts, the gatefold's locked sleeve-interior colors (`11-gatefold.css`), the stock paper tokens and real pressing palettes (Oxblood, Verdigris, Pine from `record-art/tiers.js`). Album names, artists and text are invented placeholders. Font and wordmark URLs in the `.dc.html` files point at the canvas's own uploads, so open the files through the canvas rather than directly.
