Miziki · placeholder sleeves

One set of four

Today's wordmark sleeve, B house, C die-cut and D embossed, used together. Each record with no art gets one, picked from its artist and album the same way pressings are, so an album wears the same sleeve everywhere. Weighted toward the two dark sleeves so a big batch of files without art stays calm. On real records every sleeve carries the hand-lettered sticker; in the launch intro and the empty crate they're plain.
