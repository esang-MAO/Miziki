# House sleeves: design handoff

The frames behind BD14b (`docs/38_BD14b_HOUSE_SLEEVES.md`): the sleeves a record gets when it has no artwork. Same format as `docs/design/fermata-icon/`. The `.dc.html` files are the design canvas's source ("Miziki Placeholder Sleeves") and won't render opened directly in a browser; flat PNGs of each are in the handoff's `frames/`.

| Artboard | File | Status |
|---|---|---|
| One set of four: the set and its odds, a crate with no art at all, mixed with real covers, the launch intro, the empty crate | `Set.dc.html` | **Decided** |
| Today's sleeve and five concepts (A Stamp, B House, C Die-cut, D Embossed, E Friend's card) | `Main.dc.html` | B, C and D kept, alongside today's wordmark sleeve |
| Each concept in a crate row among real covers | `Crate.dc.html` | Reference |

Decided: four sleeves used together: wordmark (today's), embossed, house and die-cut. One per album, picked from artist + album, weighted 3/3/2/2 toward the dark two. The die-cut has the whole fermata cut out, so the record's own pressing shows through the arch and the dot. Real records carry a hand-lettered title sticker; the launch intro and the empty crate use plain sleeves. Dropped: A (a corner stamp, lost below 96 px) and E (a friend's no-art card stays as it is). The cover stand-ins in the crate frames are abstract placeholders, not real artwork, and the sticker titles are sample text.
